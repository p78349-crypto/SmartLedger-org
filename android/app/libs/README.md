# Google AI Edge SDK (로컬 AAR)

## 설치 방법

1. Google AI Edge SDK AAR 파일을 다운로드합니다:
   - 공식 배포가 시작되면: https://developer.android.com/ai/edge
   - 또는 빌드 가이드: https://github.com/google/generative-ai-android

2. AAR 파일을 이 폴더에 복사합니다:
   ```
   android/app/libs/generativeai-0.1.0.aar
   ```

3. 빌드 시 자동으로 포함됩니다.

## 대안

AAR 파일이 없어도 앱의 다른 기능들은 정상 작동합니다.
온디바이스 AI 기능만 사용할 수 없게 됩니다.
