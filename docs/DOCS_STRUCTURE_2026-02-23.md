## 폴더 기준
- `docs/developer`: 개발 참고/설계/구현/마이그레이션/연동 문서
- `docs/user-manual`: 사용자 가이드/체크리스트/사용 절차 문서

- `docs/reports`: 분석/리포트/감사/요약 문서
- `docs/policies`: 규칙/정책/보안 준수 문서
