#### 최종 해결 (모바일 UI 버튼)

**추가된 메서드**:

```dart
/// 메모 입력 필드 (공통)
Widget _buildMemoField({
  required VoidCallback onSubmitted,
}) {
  return TextFormField(
    controller: _memoController,
    textInputAction: TextInputAction.done,
    onFieldSubmitted: (_) => onSubmitted(),
    onChanged: (_) => setState(() {}),
    decoration: InputDecoration(
      labelText: '메모',
      border: const OutlineInputBorder(),
      hintText: '예: 마트 이름 + 간단 메모',
      suffixIcon: _memoController.text.isNotEmpty
          ? IconButton(
              icon: const Icon(Icons.clear),
              onPressed: () => setState(_memoController.clear),
            )
          : null,
    ),
  );
}

/// 저장 + 저장후계속 버튼
Widget _buildSaveButtons() {
  return Align(
    alignment: Alignment.centerRight,
    child: Row(
      mainAxisSize: MainAxisSize.min,
      children: [
        IconButton.filled(
          onPressed: _saveAndContinue,
          tooltip: '저장 후 계속',
          icon: const Icon(Icons.arrow_forward),
        ),
        const SizedBox(width: 8),
        IconButton.filled(
          onPressed: _saveTransaction,
          tooltip: '저장',
          icon: const Icon(Icons.check),
        ),
      ],
    ),
  );
}

/// 거래 저장 후 계속 입력
Future<void> _saveAndContinue() async {
  await _saveTransaction();
}
```

**변경된 필드**:
- `_buildSavingsFields()`: `_buildMemoField()`, `_buildSaveButtons()` 사용
- `_buildIncomeFields()`: `_buildMemoField()`, `_buildSaveButtons()` 사용  
- `_buildExpenseFields()`: `_buildMemoField()`, `_buildSaveButtons()` 사용

**UI 구성**:
```
[메모 입력 필드]
  └─ 메모 값이 있으면 X 버튼 표시
  └─ Enter/완료 누르면 저장

[저장 버튼]
  > ✓
  └─ > : 저장 후 계속 입력 (폼 초기화)
  └─ ✓ : 저장
```

**동작 방식**:
1. **스마트폰 소프트 키보드**: 메모 필드에서 "완료" 버튼 누르면 저장
2. **스마트폰 터치**: UI 버튼으로 저장/계속 입력
3. **반복 입력 시**: 
   - ">" 버튼으로 상품명, 메모, 수량, 단가, 금액 초기화
   - 거래 유형, 날짜, 결제수단, 카테고리 유지
   - 다음 지출입력 준비
