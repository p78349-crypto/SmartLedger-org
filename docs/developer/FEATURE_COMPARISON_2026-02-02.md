## 🎯 핵심 차이점

### 1. 목적과 용도

**식료품/생활용품:**
- **빠른 지출 기록**을 위한 템플릿 기능
- 자주 구매하는 10가지 품목을 미리 정의
- 클릭 한 번으로 거래 입력 화면으로 이동
- 입력 시간: **약 10초**

**유통기한 관리:**
- **재고와 유통기한 추적**을 위한 관리 시스템
- 품목별 유통기한, 수량, 위치 등 상세 정보 저장
- D-day 알림으로 식품 폐기 방지
- 입력 시간: **약 30초**

### 2. 데이터 흐름

**식료품/생활용품:**
```
템플릿 선택 → 거래 입력 화면 → 거래 저장
(임시 데이터) → (Transaction) → (영구 저장)
```

**유통기한 관리:**
```
품목 등록 → 유통기한 DB 저장 → 지속적 관리
(입력) → (FoodExpiryItem) → (영구 저장 + 모니터링)
```

### 3. UI 구조

**식료품/생활용품:**
- 3열 그리드 레이아웃
- 10개 고정 품목 (쌀, 라면, 휴지 등)
- 각 카드: 아이콘 + 이름 + 평균가격
- 하단 재고관리 버튼

**유통기한 관리:**
- 리스트 뷰 레이아웃
- 동적 품목 (사용자가 추가)
- 각 항목: 이름 + 유통기한 + D-day + 수량 + 위치
- 필터링: 전체/냉장/냉동/실온

| **공급처** | 없음 | 선택 입력 |
| **메모** | 거래 시 입력 | 선택 입력 |

### 주요 기능

| 기능 | 식료품/생활용품 | 유통기한 관리 |
|------|----------------|--------------|
| **빠른 입력** | ✅ 핵심 기능 | ❌ 상세 입력 필요 |
| **유통기한 알림** | ❌ 없음 | ✅ D-day 표시 |
| **재고 추적** | ❌ 없음 | ✅ 수량 관리 |
| **위치 관리** | ❌ 없음 | ✅ 냉장/냉동/실온 |
| **평균가격 표시** | ✅ 템플릿에 포함 | ❌ 없음 |
| **거래 기록** | ✅ 자동 생성 | ✅ 선택적 연동 |
| **FIFO 정렬** | ❌ 없음 | ✅ 유통기한순 |

### 사용 시나리오

**식료품/생활용품 사용 예시:**
1. 마트에서 라면 구매
2. 앱 실행 → 메인 페이지 2 → 생활용품 아이콘
3. "라면" 카드 클릭
4. 금액만 입력 (3,500원)
5. 저장 완료 (10초 소요)

**유통기한 관리 사용 예시:**
1. 마트에서 우유 구매
2. 앱 실행 → 메인 페이지 1 → 유통기한 관리
3. "추가" 버튼
4. 품목명, 금액, 유통기한, 수량, 위치 입력
5. 저장 후 지속적으로 D-day 확인 (30초 소요)

## 💡 선택 가이드

### 식료품/생활용품을 사용하세요:
- ✅ 빠르게 지출만 기록하고 싶을 때
- ✅ 자주 구매하는 생필품(쌀, 라면, 휴지 등)
- ✅ 유통기한 걱정 없는 품목
- ✅ 장기 보관 가능한 품목
- ✅ 단순 가계부 기록이 목적

### 유통기한 관리를 사용하세요:
- ✅ 유통기한이 중요한 식품
- ✅ 냉장/냉동 보관 필요한 품목
- ✅ 재고 수량을 추적하고 싶을 때
- ✅ 식품 폐기를 방지하고 싶을 때
- ✅ 여러 개를 한꺼번에 구매한 경우
- ✅ D-day 알림이 필요할 때

## 📈 통계 및 분석

### 식료품/생활용품
- ✅ 거래 기록 기반 통계 (Transaction 데이터)
- ✅ 카테고리별 지출 분석
- ✅ 기간별 소비 패턴
- ✅ 전체 가계부 통계에 포함

### 유통기한 관리
- ⚠️ 별도 통계 없음 (데이터 구조가 다름)
- ✅ 재고 현황 조회
- ✅ 유통기한 임박 품목 확인
- ✅ 위치별 재고 분석

## 📝 결론

**식료품/생활용품**과 **유통기한 관리**는 서로 **보완적인 관계**입니다:

- **식료품/생활용품**: 속도 중심 (Fast Input)
- **유통기한 관리**: 관리 중심 (Detail Management)

사용자는 상황에 따라 적절한 기능을 선택하여 사용하면 됩니다. 두 기능을 병행 사용하면 더욱 효과적인 가계부 및 재고 관리가 가능합니다.
