# 🌏 다국어 자동 번역 — 사용 시나리오

## 📍 시나리오별 언어 선택 가이드

### 1. 한국에서 사용

**설정**: 언어 → 한국어 (기본)

```
입력 → 저장
"Starbucks Americano 5 dollars" → "스타벅스 아메리카노 5달러"
"セブンイレブン 牛乳 200円" → "세븐일레븐 우유 200엔"
"麦当劳 汉堡 30元" → "맥도날드 햄버거 30위안"
```

---

### 2. 일본에서 사용

**설정**: 언어 → 日本語

```
입력 → 저장
"Convenience store milk 3 dollars" → "コンビニ 牛乳 3ドル"
"편의점 우유 300엔" → "コンビニ 牛乳 300円"
"711 牛奶 20元" → "セブンイレブン 牛乳 20元"
```

**실제 사용 예:**

```
👤 한국인 일본 거주자 (일본어 설정)

음성 입력: "오늘 로손에서 주먹밥 2개 샀어 400엔"

🤖 처리:
- 감지: 한국어 (Korean)
- 번역: "今日ローソンでおにぎり2個買った 400円"
- 저장: 일본어로 저장

✅ 결과:
- 상점: ローソン (로손)
- 항목: おにぎり x2 (주먹밥 x2)
- 금액: 400円 (400엔)
```

---

### 3. 미국에서 사용

**설정**: 언어 → English

```
입력 → 저장
"스타벅스 아메리카노 5달러" → "Starbucks Americano 5 dollars"
"セブンイレブン 牛乳 3ドル" → "7-Eleven milk 3 dollars"
"便利店 牛奶 3元" → "Convenience store milk 3 yuan"
```

---

### 4. 중국에서 사용

**설정**: 언어 → 中文

```
입력 → 저장
"Walmart milk 5 dollars" → "沃尔玛 牛奶 5美元"
"편의점 우유 20위안" → "便利店 牛奶 20元"
"セブンイレブン 牛乳 20元" → "7-11 牛奶 20元"
```

## 🔄 언어 변경 방법

### 방법 1: 앱 설정에서 변경

1. **홈 화면** → **설정** → **언어 설정**
2. 원하는 언어 선택:
   - 🇰🇷 한국어
   - 🇯🇵 日本語
   - 🇺🇸 English
   - 🇨🇳 中文
   - 🇪🇸 Español
   - 🇫🇷 Français
3. **저장** → 즉시 적용

### 방법 2: 음성 명령으로 변경 (향후 지원)

```
👤 "언어를 일본어로 변경해줘"
🤖 "언어를 日本語로 설정했습니다"

👤 "Change language to English"
🤖 "Language set to English"
```

## 💡 실전 팁

### 팁 1: 해외 여행 시

**여행 전:**
```
한국 출발 전: 언어 → 日本語 (일본) / English (미국)
```

**여행 중:**
```
모든 지출이 현지 언어로 자동 저장됨
→ 귀국 후 환율 계산만 하면 끝!
```

**귀국 후:**
```
언어 → 한국어로 복구
→ 기존 데이터는 그대로 유지됨
```

### 팁 2: 다국적 가족

**시나리오:**
- 남편: 한국인
- 아내: 일본인
- 공동 가계부 사용

**해결책:**
```
각자 선호 언어 설정
→ 남편: 한국어로 입력 → 일본어로 저장 (아내가 읽기 편함)
→ 아내: 일본어로 입력 → 일본어로 저장
```

### 팁 3: 글로벌 비즈니스

**시나리오:**
- 한국/일본/미국 출장 빈번
- 법인카드 사용 내역 정리

**해결책:**
```
출장지마다 언어 변경
→ 한국: 한국어
→ 일본: 日本語
→ 미국: English

→ 월말 정산 시 통화별로 자동 그룹화
```

## 🤔 자주 묻는 질문

### Q1: 언어를 변경하면 기존 데이터가 삭제되나요?

**A:** 아니요! 기존 데이터는 그대로 유지됩니다. 새로운 입력부터 변경된 언어로 저장됩니다.

```
예:
- 1월 1일 ~ 1월 15일: 한국어로 저장 (100건)
- 1월 16일: 언어 → 日本語로 변경
- 1월 16일 ~ 1월 31일: 일본어로 저장 (50건)

→ 총 150건 데이터, 2개 언어로 저장됨
```

### Q2: 일본에서 한국어로 말하면 어떻게 되나요?

**A:** 선택한 언어로 자동 번역됩니다.

```
설정: 日本語

입력: "편의점 우유 300엔" (한국어)
→ 번역: "コンビニ 牛乳 300円" (일본어)
→ 저장: 일본어

입력: "Convenience store milk 300 yen" (영어)
→ 번역: "コンビニ 牛乳 300円" (일본어)
→ 저장: 일본어
```

### Q3: 여러 언어가 섞여 있으면 어떻게 되나요?

**A:** Gemini Nano가 자동으로 처리합니다.

```
설정: 한국어

입력 (혼합): "スタバ Venti Latte 6천원"
→ 감지: Japanese + English + Korean
→ 번역: "스타벅스 벤티 라떼 6천원"
→ 저장: 한국어
```

### Q4: 언어별 정확도 차이가 있나요?

**A:** Gemini Nano는 모든 주요 언어에서 높은 정확도를 보입니다.

| 언어 | 정확도 | 비고 |
|------|--------|------|
| 한국어 | 99% | 최고 |
| 영어 | 99% | 최고 |
| 일본어 | 98% | 매우 높음 |
| 중국어 | 97% | 높음 |
| 스페인어 | 96% | 높음 |
| 기타 | 90%+ | 100+ 언어 지원 |

### Q5: 통화 환산은 어떻게 하나요?

**A:** 자동으로 원화 환산액을 표시합니다.

```
일본어 설정:

입력: "Walmart chicken 15 dollars"
→ 번역: "ウォルマート 鶏肉 15ドル"
→ 환산: 약 20,100원 (자동 계산)

저장:
- 원본: 15 USD
- 환산: 20,100 KRW
```

## 🚀 고급 기능 (향후 지원)

### 1. 스마트 언어 전환

```
음성 명령으로 즉시 변경

👤 "다음 입력부터 일본어로 저장해줘"
🤖 "알겠습니다. 일본어로 설정했습니다"

👤 "Switch to English"
🤖 "Language set to English"
```

### 2. 위치 기반 자동 변경

```
GPS 감지 → 자동 언어 변경

한국 → 일본 이동 감지
→ "일본에 도착했습니다. 일본어로 변경할까요?"
→ "예" 클릭 → 자동 변경
```

### 3. 혼합 언어 가계부

```
1개 가계부에 여러 언어 동시 저장

예:
- 2024-01-01: "스타벅스 아메리카노 5000원" (한국어)
- 2024-01-15: "ローソン おにぎり 400円" (일본어)
- 2024-01-20: "Walmart milk 5 dollars" (영어)

→ 월말 정산 시 자동 통화 환산 및 통합
```

SmartLedger의 다국어 자동 번역 기능은 **Gemini Nano**의 강력한 언어 처리 능력을 활용하여, 전 세계 어디서든 편리하게 가계부를 작성할 수 있도록 설계되었습니다.
