└─ 비용: 무료

## 🏗️ 통합 아키텍처 제안

### **3계층 바코드 검색 시스템**

```
바코드 스캔
    ↓
1️⃣ L1: 로컬 캐시 (최근 1000개)
   ├─ 메모리: ~1MB
   ├─ 응답: <1ms
   └─ 히트율: ~60-80%
    ↓ (미스)
2️⃣ L2: 로컬 DB (한국 3000개)
   ├─ SQLite DB
   ├─ 메모리: ~2MB
   ├─ 응답: <10ms
   └─ 히트율: ~100% (한국)
    ↓ (미스)
3️⃣ L3: 온라인 API (OpenFoodFacts)
   ├─ 글로벌 검색
   ├─ 응답: 100-500ms
   └─ 모든 바코드 (100만개)
    ↓ (완료/미스)
4️⃣ 신규 상품 등록
   └─ 사용자 입력 → DB 저장
```
