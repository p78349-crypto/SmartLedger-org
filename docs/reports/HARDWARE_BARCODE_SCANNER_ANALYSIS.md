## 📊 시스템 아키텍처 개요

```
하드웨어 바코드 스캐너 
       ↓ (USB / Bluetooth)
   플러터 앱 (TextField 포커스)
       ↓ (자동 문자 입력 + Enter)
  _barcodeController (TextEditingController)
       ↓ onSubmitted 콜백
_handleBarcodeSubmit() 호출
       ↓
바코드 검색 (DB 쿼리)
       ↓
수량 필드 자동 포커스
       ↓
FocusNode.requestFocus(_quantityFocus)
       ↓
사용자 또는 스캐너 입력 (수량)
       ↓
Enter 키 또는 [저장] 버튼
       ↓
_handleQuantitySubmit() 실행
       ↓
DB 저장 + 리스트 추가 + 필드 초기화
       ↓
바코드 필드로 자동 복귀
       ↓
다음 바코드 스캔 대기
```

## 🎯 하드웨어 스캐너와의 무료 통합 메커니즘

### **1️⃣ 스캐너 입력 방식 (기본 원리)**

| 항목 | 설명 |
|------|------|
| **입력 방식** | HID (Human Interface Device) 처럼 동작 |
| **동작** | 바코드 읽음 → 텍스트 시뮬레이션 입력 → 자동 Enter 전송 |
| **Flutter 인식** | 일반 키보드 입력과 동일하게 처리 |
| **필요한 코드** | **0줄** (이미 TextField.onSubmitted로 처리됨) |

### **2️⃣ 현재 폼과의 자동 호환성**

```dart
TextField(
  focusNode: _barcodeFocus,
  controller: _barcodeController,
  onSubmitted: _handleBarcodeSubmit,  // ← 스캐너 자동 Enter와 호환
  keyboardType: TextInputType.text,
)
```

**스캐너가 하는 일**:
```
1. 바코드 읽음: "4920000113961"
2. 문자 입력 시뮬레이션: TextField에 "4920000113961" 입력
3. Enter 키 자동 전송: onSubmitted 콜백 자동 실행
```

**Flutter가 하는 일**:
```dart
onSubmitted: _handleBarcodeSubmit,  // ← 자동 호출됨
// 내부에서 바코드 검색 & 수량 필드로 자동 포커스
```

### **3️⃣ 입력 흐름 예시 (실제 동작)**

```
T=0s:   스캐너 켜짐 → 바코드 필드 자동 포커스 ✓
        
T=2s:   "우유" 바코드 스캔
        → _barcodeController: "4920000113961"
        → onSubmitted 자동 호출
        → _handleBarcodeScanned("4920000113961")
        → DB 검색 → "우유" 발견 ✓
        → 수량 필드 자동 포커스
        → SnackBar: "✓ 우유 (수량: 1)"
        
T=3s:   스캐너로 "입고" 버튼 입력 (또는 수동 입력)
        → _quantityController: "10"
        → Enter 전송
        → onSubmitted 자동 호출
        → _handleQuantitySubmit()
        → ✓ DB 저장 (2→12개)
        → ✓ 리스트 추가
        → ✓ 필드 초기화
        → ✓ 바코드 필드로 자동 포커스
        
T=5s:   [다음 바코드 준비 완료] ← 모두 자동!
```

### **상황 3: 스캐너 오류 대응**

| 발생 상황 | 현재 동작 | 결과 |
|---------|---------|------|
| **존재하지 않는 바코드** | OrElse → 새 항목 생성 | 임시 품목으로 추가 가능 |
| **빈 바코드** | 검사: `if (barcodeValue.isEmpty) return` | 무시됨 |
| **음수 수량** | 검사: `if (quantity <= 0)` → SnackBar | 거부됨 |
| **Double Enter** | 두 번 Enter 눌림 | 첫 번째만 처리 (_isProcessing 플래그) |
| **포커스 손실** | 사용자가 다른곳 클릭 | 수동 포커스 복귀 필요 |

- 월 처리 시간: 16분 × 20일 = 320분 = ~5시간

절감 효과:
- 시간 절감: 27시간 - 5시간 = 22시간/월
- 연간 인건비 절감: ~4,400,000원
- 스캐너 가격: 200,000원 (일회성)
- ✅ ROI: 회수 기간 = 0.5개월 (15일)
