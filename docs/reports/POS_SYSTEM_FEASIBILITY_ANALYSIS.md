### **개발 1️⃣: 판매 거래 모드 추가**

```dart
// 현재 (WMS 재고 관리):
if (isInbound) {
  // 입고 처리
  stock += quantity;
}

// 필요한 것 (판매 처리):
if (isSale) {
  // 판매 거래 생성
  Transaction sale = Transaction(
    type: '판매',
    amount: price * quantity,
    category: '매출',
    date: DateTime.now(),
    account: selectedAccount,
    description: '${itemName} × ${quantity}개',
  );
  await TransactionService.instance.addTransaction(sale);
  
  // 재고 감소
  stock -= quantity;
}
```

## 💰 경제성 분석

### **기존 포스 시스템 vs SmartLedger 포스**

| 항목 | 기존 포스 | SmartLedger 포스 |
|------|---------|-----------------|
| **초기 비용** | $200-500/대 | $300-700/대 |
| **월 구독료** | $50-100 | $0 (일회성) |
| **연간 비용** | $600-1,200 | $0 (유지보수만) |
| **5년 총비용** | $3,000-5,000 | $300-700 |
| **기능 확장성** | 낮음 | 높음 (오픈소스) |
| **재고 관리** | 별도 앱 필요 | 통합 ✅ |

**결론**: 
```
SmartLedger 포스 = 78% 비용 절감 💰
+ 재고 관리 통합 (추가 가치)
+ 자유로운 커스터마이징
```

### **비용-편익 분석**

```
초기 투자:
- 개발 비용: 0원 (이미 WMS 완성)
- 핸드웨어: 300-700원 × 대수
  (예: 3대 = 900,000-2,100,000원)
  
연간 편익:
- 기존 포스 구독료 절감: 180만 × 3 = 540만원/년
- 시간 절감: 재고 자동 관리 (1시간/일 × 20일 = 20시간)
  = 400,000원 × 2명 = 800,000원/년

1년 ROI: 540 + 80 = 620만원 (투자 회수 가능!)
```
