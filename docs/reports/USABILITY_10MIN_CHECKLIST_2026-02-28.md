# SmartLedger 실사용 점검 체크리스트 (10분 내 성공률)

- 작성일: 2026-02-28
- 목적: 초보 사용자가 10분 안에 핵심 기능을 스스로 완료할 수 있는지 검증
- 대상 빌드: 현재 메인 브랜치 로컬 빌드

## 1) 평가 기준 (합격/보완)

- 핵심 성공 조건
  - 10분 내 핵심 플로우 4개 중 3개 이상 완료
  - 치명적 이탈(앱 종료, 막힘, 데이터 유실) 0건
- 판정
  - 합격: 성공 조건 충족 + 치명 오류 0
  - 보완: 성공 플로우 2개 이하 또는 치명 오류 1건 이상

## 2) 10분 테스트 시나리오

### 시나리오 A: 계정 진입 (목표 2분)
- 작업
  - 앱 실행
  - 계정 선택 또는 새 계정 생성
  - 메인 화면 진입 확인
- 체크
  - [ ] 2분 내 진입 완료
  - [ ] 사용자가 도움 없이 다음 화면으로 이동 가능
  - [ ] 혼동 문구/버튼 발견 시 메모

### 시나리오 B: 장바구니 → 지출 입력 연동 (목표 3분)
- 작업
  - 장바구니에서 항목 추가
  - 지출 입력 화면으로 이동
  - 항목/금액/수량 자동 반영 확인 후 저장
- 체크
  - [ ] 데이터 자동 이관 동작 확인
  - [ ] 결제수단/메모/카테고리 선택 후 저장 완료
  - [ ] 저장 후 일일 지출 화면에서 반영 확인

### 시나리오 C: 반복 입력 효율성 (목표 2분)
- 작업
  - 두 번째 지출 입력 수행
  - 이전 입력값(결제수단/메모 등) 제안/유지 확인
- 체크
  - [ ] 반복 작업 시 입력 단계 감소 체감
  - [ ] 커서 이동/엔터 저장 흐름 자연스러움
  - [ ] 오입력 유도 요소 없음

### 시나리오 D: 안전장치/복구 신뢰성 (목표 3분)
- 작업
  - 백업 생성
  - 백업 파일 존재 확인
  - (가능 시) 테스트 계정 복원 시나리오 1회
- 체크
  - [ ] 백업 성공 메시지 확인
  - [ ] 백업 파일 경로 확인
  - [ ] 복원 후 핵심 데이터(거래 1건 이상) 확인

## 3) 관찰 지표 (정량)

- 완료율: 완료한 시나리오 수 / 4
- 소요시간: 각 시나리오 완료 시간
- 클릭/탭 수: 저장 완료까지 입력 동작 수
- 오류율: 되돌아가기/재시도/오입력 횟수
- 도움 요청 횟수: 사용자가 외부 도움 요청한 횟수

## 5) 즉시 개선 우선순위 규칙

- P1: 저장 실패, 데이터 누락, 진입 불가, 복원 불가
- P2: 핵심 플로우 10분 초과, 반복 입력 불편, 오입력 잦음
- P3: 문구 혼동, 배치 미세 불편, 학습 비용 증가 요소

## 6) 권장 실행 방법

- 최소 3명(초보 2 + 기존 사용자 1)으로 같은 체크리스트 반복
- 공통 문제 2회 이상 재현 시 즉시 P1/P2로 승격
- 수정 후 동일 시나리오 재측정해 전/후 시간 비교
