## 개요

앱 전체에 분산되어 있던 **레시피 추천 로직**을 통합했습니다.
- 여러 화면에서 중복된 레시피 추천 코드 제거
- 중앙 집중식 `UnifiedRecipeRecommendationService` 구현
- 일관된 추천 알고리즘 적용

## 문제점 분석

### 이전 상태: 레시피 추천 분산

| 위치 | 기능 | 문제점 |
|------|------|--------|
| `recipe_recommendation_utils.dart` | 일반 레시피 추천 로직 | 독립적인 유틸리티 |
| `daily_recipe_recommendation_utils.dart` | 일일 추천 | 별도 로직 |
| `daily_recipe_recommendation_widget.dart` | 위젯 표시 | 별도 구현 |
| `voice_dashboard_screen.dart` | 음성 명령 추천 | 독립된 루프 (72줄) |
| `recipe_management_screen.dart` | 추천 레시피 리스트 | 관리만 담당 |

**문제**:
- 동일한 추천 로직이 여러 곳에 중복
- 음성 명령의 복잡한 수동 레시피 매칭 (72줄 코드)
- 각 화면마다 다른 알고리즘 사용 가능성
- 유지보수 어려움

## 솔루션: UnifiedRecipeRecommendationService

### 새로운 중앙 서비스

**파일**: [lib/services/unified_recipe_recommendation_service.dart](lib/services/unified_recipe_recommendation_service.dart)

```dart
class UnifiedRecipeRecommendationService {
  // 1. 일반 추천
  Future<Map<String, RecipeMatch>> getRecommendedRecipes(...)
  
  // 2. 상위 N개 추천
  Future<List<RecipeMatch>> getTopRecommendations(...)
  
  // 3. 일일 추천
  Future<DailyRecipeRecommendationResult> getDailyRecommendation(...)
  
  // 4. 음성 명령용 추천 (새로운!)
  Future<Map<String, dynamic>?> getRecommendationForVoiceCommand(...)
  
  // 5. 식재료로 검색
  Future<List<RecipeMatch>> findRecipesByIngredients(...)
  
  // 6. Recipe 객체로 변환
  Future<List<Recipe>> convertToRecipes(...)
}
```

### 주요 기능

#### 1. 일반 레시피 추천
```dart
final recommendations = await UnifiedRecipeRecommendationService.instance
    .getRecommendedRecipes(
  items: inventory,
  minMatchPercentage: 50,
);
// 반환: {레시피명: RecipeMatch}
```

#### 2. 상위 추천
```dart
final topRecipes = await UnifiedRecipeRecommendationService.instance
    .getTopRecommendations(
  count: 5,
  minMatchPercentage: 50,
);
// 반환: List<RecipeMatch> (정렬됨)
```

#### 3. 일일 추천 (1개만)
```dart
final daily = await UnifiedRecipeRecommendationService.instance
    .getDailyRecommendation();
// 반환: DailyRecipeRecommendationResult
```

#### 4. 음성 명령 추천 (새로운!)
```dart
final voiceRec = await UnifiedRecipeRecommendationService.instance
    .getRecommendationForVoiceCommand();
// 반환: {recipe: Recipe, missingCount: int, missing: List<String>}
// - 100% 일치 우선
// - 없으면 최고 일치도 반환
```
