# 자산/ROOT 아이콘 스모크 체크리스트 (2026-02-23)

목적: "아이콘은 보이는데 반응 없음" 증상의 재발 여부를 빠르게 확인
대상 빌드: release APK (설치 완료 기준)

## 1) 기본 탭 반응 확인
- [ ] 메인에서 `자산` 페이지 아이콘 3개 이상 탭
- [ ] 각 탭에서 화면 전환 또는 보안 잠금 화면이 즉시 표시됨
- [ ] 탭 후 무반응(아무 화면 변화 없음) 없음

## 2) 자산 보안 ON 상태
- [ ] 자산 보안 활성화 후 앱 재시작
- [ ] 자산 아이콘 탭 시 잠금 화면 진입
- [ ] `인증하기` 클릭 시 인증 플로우 진입
- [ ] 인증 성공 후 대상 화면 진입

## 3) 자산 보안 OFF 상태
- [ ] 자산 보안 비활성화 후 앱 재시작
- [ ] 자산 아이콘 탭 즉시 화면 진입
- [ ] 잠금 화면이 뜨지 않음

## 4) ROOT 보안: biometric 모드
- [ ] ROOT 보안을 biometric로 설정
- [ ] 기기 생체인증 가능 환경: 생체인증 성공 시 ROOT 화면 진입
- [ ] 기기 생체인증 불가 환경: 비밀번호 인증으로 fallback 표시 후 진입 가능

## 5) ROOT 보안: password/pin 모드
- [ ] password/pin 각각에서 ROOT 아이콘 탭
- [ ] 올바른 인증 시 진입
- [ ] 잘못된 인증 시 에러 메시지 표시, 앱 프리징 없음

## 6) 회귀 체크
- [ ] 앱 완전 종료 후 재실행 3회 반복
- [ ] 각 회차에서 자산/ROOT 아이콘 첫 탭 반응 정상
- [ ] 설정 변경(보안 ON/OFF) 후에도 첫 탭 반응 정상

## 판정 기준
- PASS: 모든 체크 항목 충족, 무반응 0건
- FAIL: 탭 후 화면 변화 없는 케이스 1건 이상
