# 구독 사용 가이드 (구매자용)

> 대상: SmartLedger 사용자(구매자)
> 목적: 구독 기능 사용, 결제/복구, 만료 대응 방법 안내

---

## 1. 구독이 필요한 기능

현재 고급 자산/통계 화면은 구독 상태가 필요합니다.

- 자산 포트폴리오 분석
- 자산 투자 로드맵
- 월간 통계(고급)
- 지출 분석(고급)

구독이 없거나 만료된 경우, 기능 진입 시 `구독 인증 필요` 화면이 표시됩니다.

---

## 2. 구독 화면 진입 방법

### 방법 A: 기능 진입 중 자동 이동

1. 구독 필요 기능 화면에 진입
2. `구독 인증 필요` 화면 표시
3. `구독 관리` 버튼 탭

### 방법 B: 설정 경로 이동

1. 설정 진입
2. `구독 관리` 메뉴 진입 (배포 버전에 따라 메뉴 위치는 다를 수 있음)

---

## 3. 구독 관리 화면에서 할 수 있는 일

- `현재 상태 확인`
  - 내 구독 상태(활성/유예/만료 등) 확인
- `구독 결제 진행`
  - 스토어 결제 요청 시작
- `구매 복구`
  - 기존 구매 내역 복구 요청

> 안내: 스토어 반영까지 수 초~수 분이 걸릴 수 있습니다. 필요 시 잠시 후 다시 상태를 확인하세요.

---

## 4. 상태별 이용 가능 여부

- `active`(활성): 사용 가능
- `grace`(유예): 정책에 따라 사용 가능
- `paused`/`expired`/`refunded`/`revoked`/`unknown`: 사용 제한

---

## 5. 자주 묻는 문제 해결

### Q1. 결제했는데 기능이 열리지 않아요

1. `구독 관리 > 현재 상태 확인`
2. 앱을 완전히 종료 후 재실행
3. `구매 복구` 실행
4. 여전히 동일하면 고객지원 문의

### Q2. 기기를 바꿨더니 구독이 사라졌어요

- 동일 스토어 계정으로 로그인 후 `구매 복구` 실행

### Q3. 환불/취소 후 기능이 잠겼어요

- 정상 동작입니다. 구독 상태가 `refunded/revoked`이면 접근이 제한됩니다.

---

## 6. 결제/해지 안내

- 결제와 해지는 각 스토어 정책을 따릅니다.
- 자동갱신, 가격, 환불 가능 여부는 스토어 구독 관리 화면에서 확인하세요.

---

## 7. 개인정보/보안 안내

- 결제 완료 자체만으로 즉시 영구 권한이 부여되지 않을 수 있습니다.
- 앱은 상태 동기화 후 접근 권한을 재평가합니다.
- 상태가 불명확하면 보안상 접근이 제한될 수 있습니다.
