## 1. SmartLedger 소개

### 1.1 SmartLedger란?

**SmartLedger**는 Flutter로 개발된 종합 가계부 앱으로, 개인 및 가구의 재무를 효율적으로 관리할 수 있도록 설계되었습니다. 단순한 거래 기록을 넘어서 자산 추적, 예산 관리, 쇼핑 계획, 재고 관리 등 다양한 기능을 제공합니다.

### 1.2 주요 특징

#### 🔐 **다중 계정 지원**
- 여러 계정을 생성하고 독립적으로 관리
- 계정별 데이터 완전 분리 (거래, 자산, 통계)
- 임시 계정 기능으로 빠른 사용 가능

#### 💰 **종합 거래 관리**
- 입금/출금/반품 거래 기록
- OCR을 통한 영수증 자동 인식
- 카테고리별 분류 및 통계
- 거래 검색 및 필터링

#### 📊 **강력한 통계 및 분석**
- 월별/연간 통계 차트
- 카테고리별 지출 분석
- 수입/지출 추세 분석
- 맞춤형 리포트 생성

#### 🛒 **스마트 쇼핑 관리**
- 쇼핑 리스트 작성 및 관리
- 가격 비교 및 최적 구매 시기 추천
- 구매 항목 체크리스트
- 쇼핑 내역을 거래로 자동 전환

#### 🏠 **재고 및 식품 관리**
- 식품 유통기한 추적
- 생필품 재고 관리
- 사용 내역 기록
- 레시피 관리

#### 💾 **안전한 백업 및 복원**
- 로컬/클라우드 백업 지원
- 자동 백업 (7일마다, 매월 1일)
- JSON 형식의 데이터 내보내기
- 복원 시 데이터 마이그레이션 지원

#### 🎨 **커스터마이징**
- 다양한 테마 (라이트/다크 모드)
- 아이콘 및 레이아웃 설정
- 언어 설정 (한국어, English, 日本語)
- 통화 설정

### 1.3 시스템 요구사항

#### Android
- Android 5.0 (API 21) 이상
- 권장: Android 13 이상
- 최소 200MB 저장 공간

#### iOS
- iOS 12.0 이상
- 권장: iOS 15 이상
- 최소 200MB 저장 공간

#### Windows
- Windows 10 이상
- 최소 500MB 저장 공간

#### Web
- Chrome 88+, Firefox 85+, Safari 14+
- 인터넷 연결 필요

## 2. 시작하기

### 2.1 앱 설치

#### Android
1. Google Play Store에서 "SmartLedger" 검색
2. "설치" 버튼 클릭
3. 설치 완료 후 "열기" 클릭

#### iOS
1. App Store에서 "SmartLedger" 검색
2. "받기" 버튼 클릭
3. Face ID/Touch ID로 인증
4. 설치 완료 후 앱 실행

#### Windows
1. Microsoft Store에서 "SmartLedger" 검색
2. "다운로드" 버튼 클릭
3. 설치 완료 후 앱 실행

#### 개발자 빌드 (직접 빌드)
```powershell
# 프로젝트 폴더로 이동
cd C:\Users\plain\SmartLedger

# 의존성 설치
flutter pub get

# Windows 앱 실행
flutter run -d windows

# Android 앱 실행 (에뮬레이터/기기 연결 필요)
flutter run

# Web 앱 실행
flutter run -d web-server
```

### 2.2 첫 실행 및 초기 설정

#### 2.2.1 시작 화면
앱을 처음 실행하면 **계정 선택/생성 화면**이 나타납니다.

**3가지 옵션:**

1. **임시로 사용하기**
   - 별도의 계정 생성 없이 바로 앱 사용
   - 데이터는 임시 계정에 저장
   - 나중에 정식 계정으로 전환 가능

2. **새 계정 만들기**
   - 새로운 계정 생성
   - 계정명 입력 (예: "가계부", "회사 경비", "여행 자금")
   - 초기 잔액 설정 (선택사항)

3. **기존 계정 선택**
   - 이미 생성한 계정 목록에서 선택
   - 복수의 계정이 있는 경우 사용

#### 2.2.2 권한 요청
앱은 다음 권한을 요청할 수 있습니다:

- **저장소 접근** (필수): 백업 파일 저장 및 복원
- **카메라** (선택): 영수증 OCR 스캔
- **알림** (선택): 예산 초과, 유통기한 알림 등

> 💡 **팁**: 모든 권한은 선택사항이며, 필요할 때마다 다시 요청할 수 있습니다.

#### 2.2.3 테마 선택
첫 실행 시 기본 테마는 **Pink Light**로 설정됩니다.

테마 변경 방법:
1. 메인 화면 → **설정** (⚙️ 아이콘)
2. **테마** 선택
3. 원하는 테마 선택 (Navy Intense, Pink Light, 시스템 기본값 등)

### 2.3 인터페이스 둘러보기

#### 메인 화면 구조
SmartLedger의 메인 화면은 **페이지 기반 아이콘 그리드** 방식으로 구성됩니다.

```
┌────────────────────────────┐
│    [페이지 레이블]          │ ← 상단 중앙 라벨
├────────────────────────────┤
│  [아이콘1] [아이콘2] [아이콘3] │
│  [아이콘4] [아이콘5] [아이콘6] │ ← 아이콘 그리드
│  [아이콘7] [아이콘8] [아이콘9] │
├────────────────────────────┤
│  ⬅️ [페이지 인디케이터] ➡️    │ ← 하단 페이지 네비게이션
└────────────────────────────┘
```

#### 주요 아이콘 설명
- 💰 **거래**: 거래 입력 및 조회
- 📊 **통계**: 통계 및 리포트
- 💎 **자산**: 자산 관리
- 🛒 **쇼핑**: 쇼핑 리스트 및 카트
- 🏠 **재고**: 식품 및 생필품 재고 관리
- ⚙️ **설정**: 앱 설정

#### 네비게이션 방법
- **좌우 스와이프**: 페이지 이동
- **아이콘 탭**: 해당 기능 실행
- **아이콘 길게 누르기**: 아이콘 편집 모드 진입 (일부 화면)

## 3. 계정 관리

### 3.1 계정이란?

SmartLedger에서 **계정(Account)**은 독립적인 재무 데이터의 집합입니다. 각 계정은 다음을 포함합니다:
- 거래 내역
- 자산 정보
- 예산 설정
- 통계 데이터

**사용 예시:**
- 개인 가계부
- 사업 경비
- 여행 자금
- 가족 공동 자금

### 3.2 계정 생성

#### 3.2.1 새 계정 만들기
**경로**: `메인 화면` → `계정 관리` → `새 계정 만들기`

**단계:**
1. **계정명 입력**
   - 예: "2026년 가계부", "유럽 여행", "사업 경비"
   - 최대 50자

2. **초기 잔액 설정** (선택사항)
   - 현재 보유 금액을 입력
   - 나중에 수정 가능

3. **통화 선택** (선택사항)
   - 기본값: KRW (한국원)
   - 지원 통화: USD, JPY, CNY 등

4. **계정 아이콘 선택** (선택사항)
   - 다양한 아이콘 중 선택
   - 계정 구별에 유용

5. **생성 완료**
   - "저장" 버튼 클릭
   - 새 계정으로 자동 전환

### 3.3 계정 선택 및 전환

#### 3.3.1 계정 전환
**경로**: `메인 화면` → `계정 관리` → `계정 선택`

**방법:**
1. 계정 목록에서 원하는 계정 선택
2. 계정이 즉시 전환됨
3. 해당 계정의 데이터가 표시됨

#### 3.3.2 최근 사용 계정
- 최근 사용한 계정이 상단에 표시됨
- 빠른 접근 가능

### 3.4 계정 관리

#### 3.4.1 계정 정보 수정
**경로**: `계정 관리` → `계정 선택` → `⚙️ 설정`

**수정 가능 항목:**
- 계정명
- 계정 아이콘
- 통화 설정
- 계정 메모

#### 3.4.2 계정 삭제
**경로**: `계정 관리` → `계정 선택` → `삭제`

**주의사항:**
- 삭제된 계정은 **휴지통**으로 이동
- 휴지통에서 30일간 보관 후 영구 삭제
- 휴지통에서 복원 가능

**삭제 단계:**
1. 삭제할 계정 선택
2. "삭제" 버튼 클릭
3. 삭제 확인 팝업에서 "확인" 클릭
4. PIN/생체인증으로 확인 (보안 설정 시)

### 3.5 임시 계정

#### 3.5.1 임시 계정 사용
- 별도 계정 생성 없이 바로 사용
- 데이터는 "임시 계정"에 저장됨
- 나중에 정식 계정으로 전환 가능

#### 3.5.2 임시 계정을 정식 계정으로 전환
**경로**: `계정 관리` → `임시 계정 전환`

**단계:**
1. 계정명 입력
2. "전환" 버튼 클릭
3. 임시 계정의 모든 데이터가 새 계정으로 이전됨

## 4. 거래 관리

### 4.1 거래란?

**거래(Transaction)**는 수입 또는 지출을 기록한 것입니다. SmartLedger는 다음 거래 유형을 지원합니다:

- **지출 (Expense)**: 돈을 쓴 기록
- **수입 (Income)**: 돈을 받은 기록
- **반품 (Refund)**: 구매 취소 또는 환불

### 4.2 거래 입력

#### 4.2.1 지출 입력 - 간단 모드
**경로**: `메인 화면` → `+ 버튼` (하단 중앙)

**빠른 입력 단계:**
1. **금액 입력**
   - 숫자 키패드로 금액 입력
   - 예: 15000 → 15,000원

2. **카테고리 선택**
   - 식사, 쇼핑, 교통, 의료 등
   - 아이콘으로 구분되어 쉽게 선택

3. **간단 메모** (선택사항)
   - 예: "점심", "커피", "택시"

4. **저장**
   - "저장" 버튼 클릭
   - 거래가 즉시 기록됨

#### 4.2.2 지출 입력 - 상세 모드
**경로**: `메인 화면` → `거래` → `상세 입력`

**상세 입력 항목:**
1. **거래 유형**: 지출/수입/반품
2. **금액**: 거래 금액
3. **카테고리**: 거래 분류
4. **결제 수단**: 현금, 카드, 계좌이체 등
5. **날짜 및 시간**: 거래 발생 일시
6. **상점명/장소**: 거래 장소
7. **메모**: 상세 설명
8. **태그**: 검색용 태그 (선택사항)
9. **영수증**: 사진 첨부 (선택사항)
10. **혜택 정보**: 카드 할인, 포인트 적립 등

**저장**:
- "저장" 버튼으로 거래 기록
- "저장 후 계속" 버튼으로 연속 입력

#### 4.2.3 OCR 영수증 스캔
**경로**: `거래 입력` → `📸 영수증 스캔`

**OCR 스캔 방법:**
1. "영수증 스캔" 버튼 클릭
2. 카메라로 영수증 촬영
3. OCR이 자동으로 정보 추출:
   - 총 금액
   - 날짜
   - 상점명
   - 품목 (부분 지원)
4. 추출된 정보 확인 및 수정
5. 저장

> 💡 **팁**: 영수증을 평평하게 펴고, 밝은 곳에서 촬영하면 인식률이 높아집니다.

#### 4.2.4 반품/환불 입력
**경로**: `거래 입력` → `반품` 선택

**반품 처리 방법:**

**방법 1: 새 반품 거래 입력**
1. 거래 유형을 "반품" 선택
2. 반품 금액 입력
3. 원래 지출 거래와 연결 (선택사항)
4. 저장

**방법 2: 기존 거래에서 반품 처리**
1. 반품할 거래 선택
2. 거래 상세 화면에서 "반품 처리" 버튼 클릭
3. 반품 금액 입력 (전체 또는 일부)
4. 저장

**반품 거래 특징:**
- 📊 지출 통계에서 **별도 집계**
- 🔄 원래 지출 금액에서 차감되지 않음
- 🎯 "반품" 카테고리로 자동 분류
- 💰 계정 잔액에 반영됨

### 4.3 거래 조회 및 검색

#### 4.3.1 거래 목록
**경로**: `메인 화면` → `거래`

**거래 목록 보기 옵션:**
- **전체**: 모든 거래 표시
- **지출만**: 지출 거래만 표시
- **수입만**: 수입 거래만 표시
- **반품만**: 반품 거래만 표시
- **날짜별**: 날짜순 정렬
- **금액별**: 금액순 정렬

#### 4.3.2 거래 검색
**경로**: `거래 목록` → `🔍 검색`

**검색 옵션:**
1. **텍스트 검색**
   - 메모, 상점명, 카테고리로 검색
   - 예: "카페", "마트", "교통"

2. **날짜 범위 검색**
   - 시작일과 종료일 지정
   - 예: 2026-01-01 ~ 2026-01-31

3. **금액 범위 검색**
   - 최소 금액과 최대 금액 지정
   - 예: 10,000원 ~ 50,000원

4. **카테고리 검색**
   - 특정 카테고리만 필터링
   - 여러 카테고리 선택 가능

5. **결제 수단 검색**
   - 현금, 카드, 계좌이체 등

6. **태그 검색**
   - 사용자 정의 태그로 검색

### 4.4 거래 상세 정보

#### 4.4.1 거래 상세 화면
**경로**: `거래 목록` → `거래 선택`

**표시 정보:**
- 거래 유형 (지출/수입/반품)
- 금액 (큰 글씨로 표시)
- 카테고리 (아이콘 + 이름)
- 날짜 및 시간
- 결제 수단
- 상점명/장소
- 메모
- 태그
- 영수증 이미지 (있는 경우)
- 혜택 정보 (할인, 포인트 등)

#### 4.4.2 거래 수정
**경로**: `거래 상세` → `✏️ 수정`

**수정 가능 항목:**
- 모든 항목 수정 가능
- 수정 이력 자동 기록 (선택사항)

**수정 단계:**
1. "수정" 버튼 클릭
2. 수정할 항목 변경
3. "저장" 버튼 클릭
4. 수정 확인 팝업에서 "확인" 클릭

#### 4.4.3 거래 삭제
**경로**: `거래 상세` → `🗑️ 삭제`

**삭제 방법:**
1. "삭제" 버튼 클릭
2. 삭제 확인 팝업에서 "확인" 클릭
3. 거래가 **휴지통**으로 이동

**휴지통:**
- 삭제된 거래는 휴지통에 30일간 보관
- 휴지통에서 복원 가능
- 30일 후 자동 영구 삭제

#### 4.4.4 거래 복제
**경로**: `거래 상세` → `복제`

**복제 기능:**
- 동일한 거래를 빠르게 재입력
- 날짜만 변경하여 저장
- 정기 지출 입력에 유용

**복제 단계:**
1. "복제" 버튼 클릭
2. 날짜 변경 (필요 시)
3. "저장" 버튼 클릭

### 4.5 카테고리 관리

#### 4.5.1 기본 카테고리
SmartLedger는 다음 기본 카테고리를 제공합니다:

**지출 카테고리:**
- 🍔 **식사** (Dining)
  - 외식, 카페, 배달음식 등
- 🛍️ **쇼핑** (Shopping)
  - 의류, 잡화, 온라인 쇼핑 등
- 🚗 **교통** (Transportation)
  - 대중교통, 택시, 주유 등
- 🏥 **의료** (Medical)
  - 병원, 약국, 건강검진 등
- 📚 **교육** (Education)
  - 학원, 도서, 온라인 강의 등
- 🎬 **엔터테인먼트** (Entertainment)
  - 영화, 공연, 여가 활동 등
- 💡 **유틸리티** (Utilities)
  - 전기, 수도, 가스, 통신 등
- 🏠 **주거** (Housing)
  - 임대료, 관리비, 수리비 등
- 📞 **통신** (Communication)
  - 휴대폰, 인터넷 요금 등
- ❓ **기타** (Others)

**수입 카테고리:**
- 💼 **월급** (Salary)
- 🎁 **보너스** (Bonus)
- 💰 **이자** (Interest)
- 📈 **배당금** (Dividend)
- 💸 **기타 소득** (Other Income)

#### 4.5.2 커스텀 카테고리 생성
**경로**: `설정` → `카테고리 관리` → `+ 추가`

**커스텀 카테고리 생성:**
1. **카테고리명 입력**
   - 예: "반려동물", "기부", "취미"
2. **아이콘 선택**
   - 다양한 아이콘 제공
3. **색상 선택**
   - 카테고리 구분용 색상
4. **저장**

### 4.6 결제 수단 관리

#### 4.6.1 결제 수단 추가
**경로**: `설정` → `결제 수단` → `+ 추가`

**지원 결제 수단:**
- 💵 **현금** (Cash)
- 💳 **신용카드** (Credit Card)
- 🏦 **체크카드** (Debit Card)
- 🔄 **계좌이체** (Bank Transfer)
- 📱 **모바일 결제** (Mobile Payment)
  - 카카오페이, 네이버페이, 삼성페이 등
- 🎁 **상품권** (Gift Card)

#### 4.6.2 카드 혜택 정보 입력
**경로**: `설정` → `결제 수단` → `카드 선택` → `혜택 정보`

**혜택 정보:**
- 할인율 (%)
- 할인 한도 (월)
- 적용 카테고리
- 포인트 적립률
- 할인 조건

**혜택 자동 계산:**
- 거래 입력 시 카드 선택하면 혜택 자동 계산
- 월별 혜택 통계에 반영

## 5. 자산 관리

### 5.1 자산이란?

**자산(Asset)**은 보유하고 있는 금전적 가치가 있는 모든 것을 의미합니다. SmartLedger에서는 다양한 유형의 자산을 추적하고 관리할 수 있습니다.

### 5.2 자산 유형

#### 5.2.1 금융 자산
- 💰 **예금**: 보통예금, 적금, 정기예금
- 📈 **투자**: 주식, 펀드, 채권
- 💎 **귀금속**: 금, 은, 보석
- 💱 **외화**: 외화 예금, 현금

#### 5.2.2 실물 자산
- 🏠 **부동산**: 아파트, 주택, 토지, 상가
- 🚗 **차량**: 자동차, 오토바이
- 📱 **전자기기**: 스마트폰, 노트북, 태블릿
- 🎨 **수집품**: 미술품, 골동품, 한정판 제품

#### 5.2.3 기타 자산
- 🎫 **상품권/포인트**: 백화점 상품권, 포인트
- 📚 **지적 재산**: 저작권, 특허
- ❓ **기타**: 분류되지 않은 자산

### 5.3 자산 추가

#### 5.3.1 자산 입력 - 기본 모드
**경로**: `메인 화면` → `자산` → `+ 추가`

**입력 항목:**
1. **자산명**: 자산 이름 (예: "삼성전자 주식", "현대차")
2. **자산 유형**: 금융 자산, 실물 자산 등
3. **초기 가치**: 구매 가격 또는 현재 평가액
4. **취득일**: 자산을 취득한 날짜
5. **메모**: 추가 정보 (선택사항)

**저장**:
- "저장" 버튼으로 자산 등록

#### 5.3.2 자산 입력 - 상세 모드
**경로**: `자산` → `상세 입력`

**추가 입력 항목:**
- **카테고리**: 세부 분류
- **수량**: 자산 개수 (주식, 귀금속 등)
- **구매 단가**: 개당 가격
- **현재 단가**: 현재 평가 단가
- **평가액**: 현재 총 가치
- **수익률**: 자동 계산
- **사진**: 자산 이미지 첨부
- **증빙 서류**: 구매 영수증, 계약서 등

### 5.4 자산 조회 및 관리

#### 5.4.1 자산 대시보드
**경로**: `메인 화면` → `자산` → `대시보드`

**표시 정보:**
- 📊 **총 자산액**: 모든 자산의 합계
- 📈 **자산 구성**: 유형별 비율 (파이 차트)
- 💹 **최근 변화**: 전월 대비 증감
- 🎯 **목표 진행률**: 자산 목표 대비 현황
- 📉 **자산 추세**: 월별 자산 변화 그래프

**차트 유형:**
- **파이 차트**: 자산 구성비
- **라인 차트**: 시간별 자산 변화
- **바 차트**: 자산 유형별 비교
- **영역 차트**: 누적 자산 변화

#### 5.4.2 자산 목록
**경로**: `자산` → `목록`

**정렬 옵션:**
- 이름순 (가나다순, ABC순)
- 금액순 (높은 금액부터)
- 날짜순 (최근 취득일부터)
- 수익률순 (높은 수익률부터)

**필터 옵션:**
- 자산 유형별 필터
- 가치 범위 필터
- 취득 기간 필터

#### 5.4.3 자산 상세 정보
**경로**: `자산 목록` → `자산 선택`

**상세 정보:**
- 자산명 및 아이콘
- 현재 평가액 (큰 글씨)
- 취득 가격
- 수익/손실 금액 및 비율
- 취득일
- 보유 기간
- 메모
- 사진/증빙 서류
- **가치 변화 그래프**: 시간별 가치 변화
- **거래 히스토리**: 구매, 매도, 평가액 조정 등

#### 5.4.4 자산 가치 업데이트
**경로**: `자산 상세` → `가치 업데이트`

**업데이트 방법:**
1. **수동 입력**
   - 현재 평가액 직접 입력
   - 날짜 지정
   - 메모 추가 (선택사항)

2. **자동 업데이트** (일부 자산)
   - 주식: 실시간 시세 연동 (선택사항)
   - 환율: 자동 환율 적용
   - 부동산: KB시세 연동 (선택사항)

#### 5.4.5 자산 이동/매도
**경로**: `자산 상세` → `이동/매도`

**매도 처리:**
1. "매도" 버튼 클릭
2. 매도 수량 입력 (일부 또는 전체)
3. 매도 가격 입력
4. 매도 날짜 선택
5. 수익/손실 자동 계산
6. 저장

**매도 후 처리:**
- 자산 수량 감소 (일부 매도) 또는 제거 (전체 매도)
- 매도 금액이 계정 잔액에 반영
- 수익/손실이 통계에 기록

### 5.5 자산 할당 및 목표

#### 5.5.1 자산 할당 설정
**경로**: `자산` → `할당 설정`

**할당 비율 설정:**
- 금융 자산: 60%
- 실물 자산: 30%
- 기타 자산: 10%

**세부 할당:**
- 예금: 30%
- 투자: 30%
- 부동산: 25%
- 기타: 15%

**할당 분석:**
- 목표 할당 vs 실제 할당 비교
- 재할당 권장사항
- 불균형 경고

#### 5.5.2 자산 목표 설정
**경로**: `자산` → `목표 설정`

**목표 설정:**
1. **목표 자산액**: 예: 1억원
2. **목표 기한**: 예: 2030-12-31
3. **월 저축액**: 자동 계산 또는 수동 입력
4. **진행률 추적**: 대시보드에 표시

## 6. 예산 및 고정비용

### 6.1 예산 관리

#### 6.1.1 예산이란?
**예산(Budget)**은 특정 기간(주로 월) 동안 지출할 수 있는 금액의 한도를 설정한 것입니다.

#### 6.1.2 월별 예산 설정
**경로**: `설정` → `예산 설정`

**예산 설정 단계:**
1. **총 월 예산 설정**
   - 예: 2,000,000원
   
2. **카테고리별 예산 분배**
   - 식사: 600,000원 (30%)
   - 쇼핑: 300,000원 (15%)
   - 교통: 200,000원 (10%)
   - 의료: 100,000원 (5%)
   - 엔터테인먼트: 200,000원 (10%)
   - 유틸리티: 300,000원 (15%)
   - 기타: 300,000원 (15%)

3. **저장**

**자동 분배:**
- "자동 분배" 버튼 클릭 시 과거 지출 패턴 기반으로 자동 설정

#### 6.1.3 예산 상태 조회
**경로**: `메인 화면` → `예산 상태`

**표시 정보:**
- 📊 **전체 예산 사용률**: 진행바로 표시
- 💰 **남은 예산**: 큰 글씨로 표시
- 🏷️ **카테고리별 예산**: 각 카테고리의 사용률
- ⚠️ **초과 경고**: 예산 초과 카테고리 강조
- 📈 **예상 지출**: 현재 추세로 예상되는 월말 지출

**색상 코딩:**
- 🟢 **녹색**: 정상 (0~70%)
- 🟡 **노란색**: 주의 (70~90%)
- 🟠 **주황색**: 경고 (90~100%)
- 🔴 **빨간색**: 초과 (100% 이상)

#### 6.1.4 예산 알림
**경로**: `설정` → `알림` → `예산 알림`

**알림 설정:**
- 📱 **예산 70% 도달**: "식사 예산의 70%를 사용했습니다"
- 📱 **예산 90% 도달**: "식사 예산의 90%를 사용했습니다. 주의하세요!"
- 📱 **예산 100% 초과**: "식사 예산을 초과했습니다!"
- 📱 **주간 리포트**: 매주 일요일 예산 사용률 리포트
- 📱 **월말 리포트**: 매월 마지막 날 예산 사용 리포트

### 6.2 고정비용 관리

#### 6.2.1 고정비용이란?
**고정비용(Fixed Cost)**은 매달 정기적으로 지출되는 비용입니다.

**예시:**
- 임대료
- 관리비
- 통신비 (휴대폰, 인터넷)
- 구독 서비스 (Netflix, Spotify 등)
- 보험료
- 자동차 할부금
- 대출 이자

#### 6.2.2 고정비용 추가
**경로**: `메인 화면` → `고정비용` → `+ 추가`

**입력 항목:**
1. **비용명**: 예: "임대료", "휴대폰 요금"
2. **금액**: 고정 금액
3. **카테고리**: 주거, 통신 등
4. **시작일**: 첫 납부일
5. **반복 주기**: 
   - 매월 (Monthly)
   - 분기별 (Quarterly)
   - 반기별 (Semi-annually)
   - 연간 (Annually)
6. **납부일**: 매월 몇 일에 납부하는지
7. **결제 수단**: 자동이체 계좌, 카드 등
8. **메모**: 추가 정보

**저장**:
- "저장" 버튼 클릭
- 고정비용 자동 알림 설정 (선택사항)

#### 6.2.3 고정비용 목록
**경로**: `고정비용` → `목록`

**목록 보기:**
- 활성 고정비용 (현재 납부 중)
- 비활성 고정비용 (종료됨)
- 예정 고정비용 (시작 전)

**정렬:**
- 날짜순 (다음 납부일)
- 금액순 (높은 금액부터)
- 이름순

#### 6.2.4 고정비용 알림
**경로**: `설정` → `알림` → `고정비용 알림`

**알림 설정:**
- 📱 **납부 7일 전**: "7일 후 임대료 납부일입니다"
- 📱 **납부 3일 전**: "3일 후 휴대폰 요금 납부일입니다"
- 📱 **납부 당일**: "오늘은 관리비 납부일입니다"
- 📱 **납부 연체**: "임대료 납부일이 지났습니다"

#### 6.2.5 고정비용 통계
**경로**: `고정비용` → `통계`

**통계 정보:**
- 📊 **월별 고정비용 합계**: 모든 고정비용의 월 합계
- 📈 **고정비용 추이**: 월별 변화 그래프
- 🏷️ **카테고리별 분석**: 고정비용의 카테고리별 비율
- 💰 **총 수입 대비 비율**: 고정비용이 수입의 몇 %인지
- 📉 **절감 제안**: AI 기반 고정비용 절감 아이디어

#### 6.2.6 고정비용 자동 입력

## 8. 쇼핑 기능

### 8.1 쇼핑 카트

#### 8.1.1 쇼핑 카트란?
**쇼핑 카트(Shopping Cart)**는_mart나 온라인에서 구매할 물품 목록을 미리 작성하고 관리하는 기능입니다.

**활용 방법:**
1. 집에서 구매할 물품 목록 작성
2. 마트에서 물품을 담으며 체크
3. 체크된 항목을 가계부에 자동 입력

#### 8.1.2 쇼핑 카트 사용법
**경로**: `메인 화면` → `쇼핑` → `카트`

**쇼핑 준비 단계:**

**1단계: 물품 추가**
1. "+" 버튼으로 물품 추가
2. **물품명 입력**: 예: "우유", "사과", "치킨"
3. **수량 입력**: 예: 2개, 1kg
4. **예상 가격 입력** (선택사항): 예: 5,000원
5. **카테고리 선택** (선택사항): 식품, 생필품 등
6. 저장

**2단계: 장보기 (마트)**
1. 쇼핑 카트 화면 열기
2. 물품을 장바구니에 담으면 해당 항목 **탭하여 체크**
   - 체크된 항목은 목록 하단으로 이동
   - 아직 구매 안 한 항목이 상단에 남음
3. 계산대에서 반환/취소된 물품은 다시 탭하여 체크 해제

**3단계: 가계부 입력**
1. 집에 도착 후 "체크 항목 지출입력" 버튼 클릭
2. 체크된 각 항목에 대해 순차적으로 입력 화면 진행:
   - 실제 구매 가격 확인/수정
   - 결제 수단 선택 (기본값 자동 입력)
   - 카테고리 확인/수정
   - 메모 추가 (예: "이마트 · 세일 상품")
3. "저장" 또는 "나머지 모두 저장" 클릭
4. 모든 항목이 가계부에 개별 거래로 입력됨

#### 8.1.3 쇼핑 카트 고급 기능

**편의 기능:**
- **자동 완성**: 자주 구매하는 물품 자동 완성
- **이전 쇼핑 불러오기**: 지난주 쇼핑 목록 재사용
- **음성 입력**: 물품명 음성으로 추가 (선택사항)
- **공유 기능**: 가족과 쇼핑 목록 공유

**정렬 옵션:**
- 카테고리별 정렬 (채소, 과일, 유제품 등)
- 가게 동선별 정렬 (마트 구역 순서)
- 우선순위별 정렬

#### 8.1.4 쇼핑 내역
**경로**: `쇼핑` → `내역`

**내역 정보:**
- 과거 쇼핑 목록
- 쇼핑별 총액
- 쇼핑 날짜
- 구매 물품 목록
- 쇼핑 통계

### 8.2 가격 비교 및 최적 구매 시기

#### 8.2.1 월별 가격 추이
**경로**: `쇼핑` → `가격 분석`

**분석 기능:**
- 특정 물품의 월별 가격 변화

**비교 기능:**
- 동일 물품의 상점별 가격 비교
- 상점별 평균 가격
- 가장 저렴한 상점 추천

### 8.3 쇼핑 통계

**경로**: `쇼핑` → `통계`

**통계 정보:**

- 🟢 **정상 식품**: D-7 이상 (녹색)

## 10. 백업 및 복원

### 10.1 백업의 중요성

데이터는 가장 중요한 자산입니다. SmartLedger는 다양한 백업 방법을 제공하여 데이터 손실을 방지합니다.

### 10.2 수동 백업

#### 10.2.1 로컬 백업
**경로**: `설정` → `백업 및 복원` → `백업`

**백업 단계:**
1. "백업 생성" 버튼 클릭
2. 백업 파일명 입력 (자동 생성: `{계정명}_YYYYMMDD.json`)
3. 백업 위치 선택:
   - 내부 저장소
   - SD 카드
   - 다운로드 폴더
4. 암호화 설정 (선택사항)
   - 백업 파일 암호 설정
   - 복원 시 암호 필요
5. "백업" 버튼 클릭
6. 백업 완료 확인

**백업 내용:**
- ✅ 모든 거래 내역
- ✅ 계정 정보
- ✅ 자산 정보
- ✅ 예산 및 고정비용 설정
- ✅ 사용자 설정
- ✅ 카테고리 및 결제 수단
- ✅ 쇼핑 카트 및 내역
- ✅ 재고 및 레시피
- ❌ 보안 설정 (PIN, 비밀번호, 생체인증)
- ❌ 영수증 이미지 (옵션에 따라 선택)

#### 10.2.2 클라우드 백업
**경로**: `설정` → `백업 및 복원` → `클라우드 백업`

**지원 클라우드:**
- ☁️ Google Drive
- ☁️ Dropbox
- ☁️ OneDrive (계획 중)

**클라우드 백업 설정:**
1. 클라우드 서비스 선택
2. 계정 로그인
3. 백업 파일명 및 폴더 지정
4. "백업" 버튼 클릭
5. 업로드 진행률 표시
6. 완료 확인

#### 10.2.3 이메일 백업
**경로**: `설정` → `백업 및 복원` → `이메일로 전송`

**이메일 백업 단계:**
1. "이메일로 전송" 버튼 클릭
2. 백업 파일 생성 (자동)
3. 이메일 앱 열림
4. 수신자 입력 (본인 이메일)
5. 제목 및 본문 (자동 생성)
6. 이메일 전송

### 10.3 자동 백업

#### 10.3.1 자동 백업 설정
**경로**: `설정` → `백업 및 복원` → `자동 백업 설정`

**자동 백업 옵션:**
- **주기**: 
  - 매일
  - 7일마다
  - 매월 1일
  - 사용 안 함
- **저장 위치**: 
  - 내부 저장소
  - SD 카드
  - 클라우드
- **보관 개수**: 
  - 최근 3개
  - 최근 5개
  - 최근 10개
  - 모두 보관

**기본 설정:**
- 7일마다 자동 백업
- 내부 저장소에 저장
- 최근 5개 보관

#### 10.3.2 자동 백업 파일명
자동 백업 파일은 다음 형식으로 생성됩니다:
```
{계정명}_YYYYMMDD_auto.json
```

**예시:**
- `가계부_20260227_auto.json`
- `여행자금_20260220_auto.json`

### 10.4 복원

#### 10.4.1 백업 파일 복원
**경로**: `설정` → `백업 및 복원` → `복원`

**복원 단계:**
1. "복원" 버튼 클릭
2. 백업 파일 선택
   - 로컬 파일 선택
   - 클라우드에서 다운로드
3. 백업 파일 정보 확인
   - 백업 날짜
   - 계정명
   - 데이터 개수
4. 복원 옵션 선택:
   - **새 계정으로 복원** (권장): 기존 데이터 유지
   - **현재 계정에 병합**: 기존 데이터 + 백업 데이터
   - **현재 계정 덮어쓰기**: 기존 데이터 삭제 (주의!)
5. 암호 입력 (암호화된 백업의 경우)
6. "복원" 버튼 클릭
7. 복원 진행률 표시
8. 완료 확인

**복원 주의사항:**
- ⚠️ **덮어쓰기** 옵션은 기존 데이터를 완전히 삭제하므로 주의
- 💡 **새 계정으로 복원**이 가장 안전한 방법
- 📝 복원 전 현재 계정을 백업하는 것을 권장

#### 10.4.2 데이터 마이그레이션
SmartLedger는 백업 파일의 구조가 변경되어도 자동으로 마이그레이션합니다.

**마이그레이션 지원:**
- 구버전 백업 파일 복원
- 필드명 변경 자동 매핑
- 데이터 구조 변환
- 누락 필드 기본값 설정

### 10.5 백업 파일 관리

## 11. 설정 및 커스터마이징

### 11.1 보안 설정

#### 11.1.0 보안 적용 범위 (중요)

SmartLedger 보안은 다음 원칙으로 동작합니다.

- 👆 **생체인식(지문/얼굴)은 공통**: 기기 보안 인증을 공통으로 사용합니다.
- 🔒 **PIN/비밀번호는 영역별 분리**:
  - ROOT PIN/비밀번호
  - 사용자 PIN/비밀번호
  - 자산 PIN/비밀번호
  각각 별도 저장소로 관리되어 서로 영향을 주지 않습니다.

예시:
- 자산 PIN을 변경해도 사용자 PIN/ROOT PIN은 변경되지 않습니다.
- 사용자 비밀번호를 해제해도 자산 비밀번호/ROOT 비밀번호는 유지됩니다.

#### 11.1.1 PIN 설정
**경로**: `설정` → `보안` → `PIN 설정`

**PIN 설정 단계:**
1. "PIN 설정" 버튼 클릭
2. 4자리 숫자 입력
3. PIN 확인 (재입력)
4. 설정 완료

**PIN 사용 시점:**
- 앱 실행 시
- 거래 삭제 시
- 계정 삭제 시
- 백업 복원 시
- 설정 변경 시 (선택사항)

**PIN 변경:**
1. "PIN 변경" 버튼 클릭
2. 현재 PIN 입력
3. 새 PIN 입력
4. 새 PIN 확인

**PIN 분실 시:**
- "PIN 분실" 버튼 클릭
- 생체인증 또는 이메일 인증으로 재설정

#### 11.1.2 생체인증
**경로**: `설정` → `보안` → `생체인증`

**지원 생체인증:**
- 👆 **지문 인식** (Fingerprint)
- 😊 **얼굴 인식** (Face Recognition)
- 🎤 **음성 인식** (Voice) - 일부 기기

**생체인증 설정:**
1. "생체인증 사용" 토글 활성화
2. 생체정보 등록 (기기 설정에서)
3. SmartLedger에서 생체인증 테스트
4. 설정 완료

**생체인증 장점:**
- 🚀 빠른 인증 (< 1초)
- 🔐 높은 보안성
- 😊 편리한 사용자 경험

5. 가져오기 진행률
6. 완료 확인

**지원 형식:**
- 은행 거래 내역 CSV
- 카드사 거래 내역 CSV
- 다른 가계부 앱의 내보내기 CSV

#### 12.3.2 다른 앱에서 마이그레이션
**경로**: `설정` → `데이터` → `다른 앱에서 가져오기`

**지원 앱:**
- 가계부 앱 (일부)
- Excel 파일
- 은행/카드사 데이터

### 12.4 휴지통

#### 12.4.1 휴지통 기능
삭제된 데이터는 즉시 영구 삭제되지 않고 **휴지통**으로 이동합니다.

**휴지통 보관 기간:**
- 30일간 보관
- 30일 후 자동 영구 삭제

**휴지통 항목:**
- 삭제된 거래
- 삭제된 자산
- 삭제된 계정

#### 12.4.2 휴지통 복원
**경로**: `설정` → `휴지통`

**복원 방법:**
1. 휴지통 열기
2. 복원할 항목 선택
3. "복원" 버튼 클릭
4. 항목이 원래 위치로 복원됨

#### 12.4.3 휴지통 비우기
**경로**: `휴지통` → `휴지통 비우기`

**영구 삭제:**
- 휴지통의 모든 항목 영구 삭제
- 복원 불가
- 확인 팝업 표시

### 12.5 루트 계정 (관리자 기능)

#### 12.5.1 루트 계정이란?
**루트 계정(Root Account)**은 여러 계정을 통합 관리하는 상위 계정입니다.

**기능:**
- 모든 계정의 통합 통계
- 계정 간 자금 이체
- 통합 백업
- 계정 관리

#### 12.5.2 루트 계정 접근
**경로**: `메인 화면` → `계정 관리` → `루트 계정`

**PIN 인증 필요** (보안 설정 시)

#### 12.5.3 통합 통계
**경로**: `루트 계정` → `통합 통계`

**통합 정보:**
- 모든 계정의 총 자산
- 모든 계정의 총 수입/지출
- 계정별 비교
- 계정별 비율

## 13. 자주 묻는 질문 (FAQ)

### 13.1 일반 질문

#### Q1. SmartLedger는 무료인가요?
**A:** SmartLedger는 기본 기능은 무료로 제공됩니다. 일부 고급 기능(클라우드 백업, AI 분석 등)은 프리미엄 구독이 필요할 수 있습니다.

#### Q2. 여러 기기에서 사용할 수 있나요?
**A:** 네, 클라우드 백업 기능을 사용하면 여러 기기에서 동일한 데이터를 사용할 수 있습니다.

#### Q3. 데이터는 안전한가요?
**A:** 네, 데이터는 기기에 암호화되어 저장되며, PIN 또는 생체인증으로 보호됩니다. 클라우드 백업도 암호화됩니다.

#### Q4. 인터넷 연결이 필요한가요?
**A:** 기본 기능은 오프라인에서 사용 가능합니다. 클라우드 백업, 환율 업데이트 등 일부 기능은 인터넷이 필요합니다.

### 13.2 계정 및 데이터

#### Q5. 계정을 몇 개까지 만들 수 있나요?
**A:** 계정 개수에 제한이 없습니다. 필요한 만큼 계정을 생성할 수 있습니다.

#### Q6. 계정을 삭제하면 데이터가 복구되나요?
**A:** 삭제된 계정은 휴지통에 30일간 보관됩니다. 이 기간 내에 복원 가능하며, 30일 후 영구 삭제됩니다.

#### Q7. 다른 가계부 앱에서 데이터를 옮길 수 있나요?
**A:** CSV 파일을 통해 데이터를 가져올 수 있습니다. 설정 → 데이터 → CSV 가져오기를 이용하세요.

### 13.3 거래 및 입력

#### Q8. 영수증 OCR 인식률이 낮은데 어떻게 하나요?
**A:** 영수증을 평평하게 펴고, 밝은 곳에서 촬영하면 인식률이 높아집니다. 그래도 인식이 안 되면 수동으로 입력할 수 있습니다.

#### Q9. 거래를 잘못 입력했는데 수정할 수 있나요?
**A:** 네, 거래 상세 화면에서 "수정" 버튼으로 언제든지 수정할 수 있습니다.

#### Q10. 반품 거래는 지출에서 차감되나요?
**A:** 아니요, 반품 거래는 별도로 집계되며 지출 통계에서 자동으로 차감되지 않습니다. 계정 잔액에는 반영됩니다.

### 13.4 백업 및 복원

#### Q11. 자동 백업은 언제 실행되나요?
**A:** 기본 설정은 7일마다 자동 백업되며, 설정에서 주기를 변경할 수 있습니다.

#### Q12. 백업 파일을 다른 기기로 옮길 수 있나요?
**A:** 네, 백업 파일(JSON)을 USB, 이메일, 클라우드 등을 통해 다른 기기로 옮긴 후 복원할 수 있습니다.

#### Q13. 복원하면 기존 데이터가 삭제되나요?
**A:** "새 계정으로 복원"을 선택하면 기존 데이터가 유지됩니다. "덮어쓰기"를 선택하면 기존 데이터가 삭제되므로 주의가 필요합니다.

### 13.5 문제 해결

#### Q14. 앱이 느려졌어요. 어떻게 하나요?
**A:** 설정 → 데이터 → 캐시 정리를 시도해보세요. 또한 오래된 거래를 아카이브하면 성능이 개선됩니다.

#### Q15. 앱이 강제 종료됩니다.
**A:** 먼저 앱을 최신 버전으로 업데이트하세요. 문제가 계속되면 설정 → 데이터 → 데이터 무결성 검사를 실행하거나, 앱을 재설치하고 백업을 복원하세요.

#### Q16. 알림이 오지 않아요.
**A:** 기기 설정 → 앱 → SmartLedger → 알림 권한이 허용되어 있는지 확인하세요. 또한 배터리 최적화에서 SmartLedger를 제외하세요.

### 13.6 연락처 및 지원

#### Q17. 문의사항이 있을 때 어디로 연락하나요?
**A:** 설정 → 도움말 → 문의하기를 통해 개발팀에 연락할 수 있습니다.

#### Q18. 기능 제안을 하고 싶어요.
**A:** 설정 → 도움말 → 피드백 보내기로 제안사항을 보내주세요. 모든 피드백은 검토됩니다.

### B. 용어 설명

- **계정 (Account)**: 독립적인 재무 데이터의 집합
- **거래 (Transaction)**: 수입 또는 지출 기록
- **자산 (Asset)**: 금전적 가치가 있는 모든 것
- **고정비용 (Fixed Cost)**: 정기적으로 지출되는 비용
- **예산 (Budget)**: 특정 기간의 지출 한도
- **카테고리 (Category)**: 거래의 분류
- **결제 수단 (Payment Method)**: 지불 방법 (현금, 카드 등)
- **루트 계정 (Root Account)**: 여러 계정을 통합 관리하는 상위 계정
