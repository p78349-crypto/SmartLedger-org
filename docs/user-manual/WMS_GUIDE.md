# WMS (Smart Home Warehouse Management System) 가이드

이 문서는 SmartLedger의 WMS(재고관리) 시스템 기능과 사용법을 설명합니다. 복잡한 입력을 최소화하고 실용성에 집중한 "Diet UI" 철학을 바탕으로 제작되었습니다.

---

## 🚀 핵심 디자인 철학: "UI Diet"
WMS의 목적은 빠른 재고 파악과 보충입니다. 입력을 방해하는 요소를 과감히 제거했습니다.
- **불필요한 필드 제거**: '건강 태그', '반복 구매 체크' 등 입력 시간을 잡아먹고 스크롤을 길게 만드는 항목을 삭제했습니다.
- **최소 입력**: 품목명(바코드), 수량, 위치만으로 즉시 입고가 가능합니다.

---

## 📂 주요 기능 안내

### 1. 집 vs 창고 탭 분리
재고 목록 화면에서 상단 탭을 통해 두 영역을 분리하여 관리합니다.
- **집 (Home)**: 주방, 욕실 등 실생활에서 바로 꺼내 쓰는 물건들입니다.
- **창고 (Warehouse)**: 다락, 베란다, 외부 창고 등 대량으로 쌓아둔 물건들입니다. (위치가 '창고'인 경우 자동으로 분류)

### 2. 하드웨어 바코드 스캐너 최적화
모든 입력창은 하드웨어 스캐너(엔터 자동 입력)와 호환되도록 설계되었습니다.
- **자동 정보 조회**: 입고 시 바코드를 찍으면 국내/글로벌 DB에서 상품명, 단위, 기본 수량을 자동으로 불러옵니다.
- **엔터(Enter) 연속 작업**: 터치 없이 스캔 -> 수량 입력 -> 엔터 만으로 입출고 처리를 끝낼 수 있습니다.
- **출고 검색**: 바코드 스캔 시 해당 품목이 즉시 선택되어 빠르게 수량을 차감할 수 있습니다.

### 3. 상단 메뉴 단일 라인화
필터 및 선택 메뉴가 화면을 가리지 않도록 한 줄로(Horizontal Scroll) 배치하여 가시성을 확보했습니다.

---

## 🛠 상세 메뉴 설명

### 📥 WMS 입고 (Inbound)
- **바코드 스캔**: 상품명 입력창에 바코드를 찍으면 즉시 정보 조회.
- **중복 처리**: 이미 있는 품목일 경우 기존 재고에 합칠지 묻는 다이얼로그 자동 표시.

### 📤 WMS 입출고 (Outbound)
- **품목 검색**: 이름이나 바코드로 원하는 품목을 즉시 필터링.
- **빠른 출고**: 수량 입력 후 엔터 키로 완료.

### ⚡ 사용량 기록 (Quick Log)
- 하루 중 소비한 양을 즉석에서 기록하여 재고에 반영합니다.

---

## 💡 사용 팁
1. **대량 구매 시**: 마트 영수증을 보고 [WMS 입고] 메뉴에서 한꺼번에 스캔하여 등록하세요.
2. **부족 알림**: 각 품목별 '알림 기준'을 설정해두면, 재고 부족 시 장바구니에 담으라는 안내가 표시됩니다.
3. **위치 관리**: '베란다', '다락' 등 상세 위치를 직접 입력하여 나중에 물건을 쉽게 찾으세요.
