
### 1. 대시보드 핵심 지표 (Health Metrics)

단순히 "살아있다"가 아니라, 엔지니어링적으로 유의미한 **4대 지표**를 정의합니다.

* **⚡ TPS (Transaction Per Second):** 현재 처리 중인 초당 트랜잭션 수 (성공/실패 분리)
* **🧠 AI Load:** Gemma 2 2B / Vision 모델의 큐 대기열 및 메모리 점유율
* **🔒 Security Pulse:** 최근 1분 내 인증 실패 횟수 및 센티넬(Sentinel) 감시 상태
* **💾 IO/Integ:** SQLite WAL 모드 동기화 상태 및 마지막 체크섬 검증 결과

### 2. 구현 설계: `tools/ops-health-dashboard.py`

이 스크립트는 서버의 `audit/timeline` API와 시스템 자원을 취합하여 **실시간 아스키(ASCII) 대시보드**를 출력합니다.

```python
# [개념 설계] SmartLedger Real-time Health Monitor
import time
import os

def render_dashboard(metrics):
    os.system('cls' if os.name == 'nt' else 'clear')
    print("="*60)
    print(f" [ SmartLedger System Heartbeat ] - {time.strftime('%Y-%m-%d %H:%M:%S')}")
    print("="*60)
    
    # 1. 인프라 상태 (The Pulse)
    print(f" [INFRA] Status: {'🟢 RUNNING' if metrics['server_up'] else '🔴 DOWN'}")
    print(f" [TPS]   Current: {metrics['current_tps']:>8} TPS | Max(24h): {metrics['max_tps']}")
    
    # 2. 보안 상태 (The Shield)
    status_icon = "🛡️" if metrics['sentinel_active'] else "⚠️"
    print(f" [SEC]   Sentinel: {status_icon} ACTIVE | Failed(1m): {metrics['failed_auth_1m']}")
    
    # 3. AI 워커 상태 (The Brain)
    print(f" [AI]    Model: Gemma-2-2B | Queue: {metrics['ai_queue_len']} | RAM: {metrics['ai_mem_usage']}%")
    
    # 4. 데이터 정합성 (The Core)
    print(f" [DB]    Mode: WAL | Sync: FULL | Integrity: {'✅ OK' if metrics['db_integ'] else '❌ ERROR'}")
    print("="*60)
    print(f" >> LAST EVENT: {metrics['last_event_msg']}")
    print("="*60)

# 무한 루프 돌며 실시간 갱신 (팀노바가 보고 있을 때 띄워두는 용도)

```

### 4. 오케스트레이션 통합 (The Final Chain)

기존 `scripts/orchestrate_lifecycle.ps1`의 마지막 단계에 이 대시보드를 연결합니다.

1. **Build/Test가 끝나면** 자동으로 대시보드 기동.
2. **임계치 초과 시(P0 경보):** 대시보드가 빨간색으로 점멸하며 `alerts-config.json`에 정의된 채널로 즉시 **"심정지(System Arrest) 위험"** 알림 발송.

## 10. 오케스트레이션 연동 명령어

`scripts/orchestrate_lifecycle.ps1`에 대시보드 연동 옵션이 추가되었습니다.

```powershell
# ops 단계 완료 후 대시보드 1회 스냅샷
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\orchestrate_lifecycle.ps1 -Stage ops -OpsDashboard once

# full 단계 완료 후 대시보드 상시 모니터링
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\orchestrate_lifecycle.ps1 -Stage full -OpsDashboard watch

# 기존 동작 유지(대시보드 비활성)
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\orchestrate_lifecycle.ps1 -Stage full -OpsDashboard none
```
