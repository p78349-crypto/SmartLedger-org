SmartLedger의 음성 기반 "빠른 재고차감" 기능에 사용된 모델 및 기술은 다음과 같습니다:

음성 인식(STT, Speech-to-Text)

패키지: speech_to_text (Dart/Flutter용)
코드 예시:
import 'package:speech_to_text/speech_to_text.dart' as stt;
→ 사용자의 음성을 텍스트로 변환
음성 텍스트의 의미 해석 및 재고차감 처리

온디바이스 AI: Google Gemini Nano (AICore, 완전 오프라인)
서비스: AICoreGeminiService
실제 호출: Android 시스템 내장 Gemini Nano, 또는 MethodChannel로 네이티브 연동
클라우드 AI: Google Gemini Flash (또는 Gemini API)
서비스: GeminiNanoService
모델명: 'gemini-2.0-flash'
패키지: google_generative_ai
정리

음성입력(STT)은 speech_to_text 패키지
자연어 해석 및 재고차감 등 실제 동작은 Google Gemini Nano(온디바이스) 또는 Gemini Flash(클라우드) 모델 사용
결론:

STT: speech_to_text
자연어 해석: Google Gemini Nano (AICore, 오프라인) 또는 Gemini Flash (gemini-2.0-flash, 클라우드)
필요시 각 서비스의 실제 코드 위치도 안내해드릴 수 있습니다.

# SmartLedger 음성입력 및 AI 모델 사용 구조

## 1. 음성 인식 (Speech-to-Text)
- **패키지:** `speech_to_text`
- **주요 사용 위치:**
  - `lib/screens/voice_dashboard_screen.dart`
    
    ```dart
    import 'package:speech_to_text/speech_to_text.dart' as stt;
    // ...
    final stt.SpeechToText _speech = stt.SpeechToText();
    ```

---

## 2. 온디바이스 자연어 해석 (Google Gemini Nano, AICore)
- **서비스 클래스:** `AICoreGeminiService`
- **파일 위치:** `lib/services/aicore_gemini_service.dart`
- **주요 코드:**

    ```dart
    /// Google AI Edge SDK (AICore)를 통한 Gemini Nano 호출
    class AICoreGeminiService {
      // ...
      Future<Map<String, dynamic>> processVoiceInput(String userSpeech) async {
        // ...
        final result = await _channel.invokeMethod<String>(
          'generateText',
          {'prompt': prompt},
        );
        // ...
      }
    }
    ```

---

## 3. 클라우드 자연어 해석 (Google Gemini Flash/API)
- **서비스 클래스:** `GeminiNanoService`
- **파일 위치:** `lib/services/gemini_nano_service.dart`
- **주요 코드:**

    ```dart
    import 'package:google_generative_ai/google_generative_ai.dart';
    // ...
    class GeminiNanoService {
      GeminiNanoService() {
        _model = GenerativeModel(
          model: 'gemini-2.0-flash', // Nano 모델 또는 Flash
          apiKey: _apiKey,
        );
      }
      // ...
      Future<Map<String, dynamic>> processVoiceInput(String userSpeech) async {
        // ...
        final response = await _model.generateContent([Content.text(prompt)]);
        // ...
      }
    }
    ```

---

## 요약
- **STT(음성→텍스트):** `speech_to_text` 패키지
- **자연어 해석:**
  - 온디바이스: Google Gemini Nano (AICore, 오프라인)
  - 클라우드: Google Gemini Flash (`gemini-2.0-flash`)

각 서비스의 실제 코드 위치와 주요 구현부를 위와 같이 정리했습니다.


정밀 분석 결과, 아래와 같이 지적재산권(IP) 관련 사항을 체크할 수 있습니다.

1. 온디바이스: Google Gemini Nano (AICore, 오프라인)
Google Gemini Nano는 Google이 직접 개발한 온디바이스 AI 모델입니다.
AICore(Google AI Edge SDK)는 공식적으로 Android 시스템에 내장된 Google의 API/SDK를 통해 접근합니다.
지적재산권:
Google이 제공하는 공식 API/SDK를 사용하면, Google의 라이선스(Play 서비스, Android 시스템, AICore SDK 약관 등)를 준수하는 한 별도의 추가 IP 문제가 발생하지 않습니다.
모델 자체를 추출·복제·역공학하지 않고, 공식 API만 호출하는 구조라면 일반적으로 앱 개발자에게 별도의 저작권/특허 위반 위험은 없습니다.
단, Google의 정책 변경, 서비스 지역 제한, 상업적 사용 조건 등은 반드시 최신 약관을 확인해야 합니다.
2. 클라우드: Google Gemini Flash (gemini-2.0-flash)
Google Gemini Flash는 Google Cloud의 Gemini API(Generative AI) 서비스의 일종입니다.
google_generative_ai 패키지 등 공식 SDK를 통해 API 호출
지적재산권:
Google Cloud Gemini API는 Google Cloud Platform(GCP) 서비스 약관 및 Gemini API 별도 약관을 따릅니다.
API를 통해 생성된 결과물(예: 텍스트, 구조화 데이터)은 일반적으로 사용자가 소유하지만, Google의 정책에 따라 일부 제한(예: 재판매, 민감정보, 금지행위 등)이 있을 수 있습니다.
API 키, 요금제, 사용량 제한, 데이터 보안 등도 반드시 확인 필요
중요: Google Gemini API의 결과물을 그대로 재배포하거나, 모델 자체를 복제/역공학하는 행위는 금지됩니다.
결론 및 권고
공식 API/SDK만 사용하고, 모델 자체를 추출·복제하지 않으면 일반적인 앱 개발/배포에는 IP 문제가 없습니다.
Google의 최신 약관, 정책, 상업적 사용 조건을 반드시 확인하세요.
상업적 서비스, 대규모 배포, 해외 서비스의 경우 Google Cloud 및 Android 관련 법무 검토를 권장합니다.
필요하다면 Google 공식 문서/약관 링크, 또는 구체적 법률 자문 안내도 제공해드릴 수 있습니다.


Google Gemini Nano(AICore)를 사용하는 다국어 앱을 출시할 경우, 다음 사항을 반드시 고려해야 합니다.

1. 라이선스 및 정책
Google Gemini Nano(AICore)는 Android 시스템에 내장된 Google 공식 AI 기능입니다.
Google의 AICore 공식 문서 및 Android 개발자 정책을 반드시 준수해야 합니다.
각 국가별 Google Play/스토어 정책, AI/데이터 관련 법률도 확인 필요
2. 다국어 지원 관련
Gemini Nano는 Android 기기 내장 AI로, 기기 언어 설정에 따라 동작이 달라질 수 있습니다.
일부 언어(특히 비영어권, 저개발국가 언어)는 인식률/지원 범위가 제한될 수 있습니다.
앱 내에서 지원하는 언어와 Gemini Nano의 실제 지원 언어를 반드시 매칭·검증해야 합니다.
3. 해외 서비스/배포 시 주의사항
Google AICore/Gemini Nano는 일부 국가(중국 등)에서 미지원 또는 제한될 수 있습니다.
데이터 처리, 개인정보 보호, AI 결과물의 법적 책임 등 각국 법률을 반드시 검토해야 합니다.
Google Play/스토어 등록 시, AI 기능 사용 및 데이터 처리 방식에 대한 명확한 고지 필요
4. 법무 검토 권장
상업적/글로벌 서비스의 경우, Google 및 현지 법률 전문가의 사전 검토를 강력히 권장합니다.
AI 결과물의 소유권, 책임, 데이터 보안, 사용자 동의 등도 별도 검토 필요
